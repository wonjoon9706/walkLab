# G7 개인 보행속도 추정 모델

## 목적과 범위

- `movement-v1`이 만든 세션별 이동 중 평균속도를 학습 단위로 사용한다.
- GPS 지점 하나를 독립된 학습 사례로 사용하지 않는다.
- 정지시간과 판정 불가 시간은 속도 학습에서 제외한다.
- G6 분석 대상 기준을 충족하지 못한 세션은 이유와 함께 제외한다.
- GPS 원본, 기존 분석 결과와 DB 스키마는 변경하지 않는다.
- 현재 결과는 기존 기록에서 결정적으로 재계산하며 별도 서버 테이블에 저장하지 않는다.

## `recency-weighted-v1` 설정

설정은 `walkingSpeedModelConfig.ts`에서 관리한다.

| 설정 | 기본값 | 의미 |
|---|---:|---|
| 기본 기간 | 30일 | 우선 사용하는 최근 기록 범위 |
| 확대 기간 | 90일 | 30일 내 유효 세션이 3개 미만일 때 확대 |
| 최소 세션 | 3개 | 개인화 추정값을 준비 완료로 표시하는 기준 |
| 시간 반감기 | 30일 | 30일이 지날 때 시간 가중치가 절반으로 감소 |
| 세션 최대 가중치 | 50% | 단일 세션이 모델을 과도하게 움직이지 않도록 제한 |
| 최소 백테스트 사례 | 2개 | 오차 비교를 표시하기 위한 평가 기록 수 |

## 계산식

세션 `i`의 기록 시점부터 계산 시점까지 경과일을 `ageDays_i`라고 할 때 원래 가중치는 다음과 같다.

```text
rawWeight_i = 0.5 ^ (ageDays_i / 30)
```

가중치 합이 1이 되도록 정규화한 뒤 한 세션의 가중치를 최대 0.5로 제한하고 남은 가중치를 다른 세션에 다시 분배한다.

```text
personalSpeed = Σ(sessionMovingSpeed_i × normalizedWeight_i)
simpleAverage = Σ(sessionMovingSpeed_i) / sessionCount
```

세션의 이동시간이나 GPS 지점 수는 추가 가중치로 사용하지 않는다. 따라서 긴 세션 하나가 모델을 지배하지 않는다. G6 기준을 통과한 정상적인 느린 보행도 속도만으로 제외하지 않는다.

1km 예상시간은 다음과 같은 현재 모델 적용 예시다.

```text
exampleSecondsFor1km = 1000m / personalSpeed(m/s)
```

이는 경사도, 경로, 신호등과 교통편을 반영한 ETA가 아니다.

## 포함·제외 기록

- 30일 내 유효 세션이 3개 이상이면 해당 기록만 사용한다.
- 부족하면 90일 내 유효 세션을 사용한다.
- 90일보다 오래된 기록은 원본을 보존하되 기본 모델에서 제외한다.
- G6 부적합, 이동속도 계산 불가, 계산 시점 이후 기록을 각각 구분한다.
- 향후 사용자 제외 UI를 추가할 수 있도록 `manuallyExcludedSessionIds` 입력과 `manually_excluded` 사유를 마련했다. 현재 UI에서는 임의로 기록을 제외하지 않는다.
- 동행·평소·빠른 걸음 같은 의미를 GPS만으로 추정하거나 저장하지 않는다.

## 갱신과 저장

기록 목록을 불러올 때 서버와 로컬의 완료 세션으로 G6 비교 결과를 한 번 만들고, 같은 결과를 G7 입력으로 재사용한다. 새 완료 세션이 동기화된 뒤 목록을 다시 계산하면 자동으로 모델에 반영된다.

초기 모델은 입력 기록과 설정이 같으면 결과도 같은 결정적 계산이다. 별도 테이블을 만들면 동기화·버전 폐기·RLS 정책이 추가로 필요하므로 현재는 저장하지 않는다. 향후 계산 비용이나 모델 이력 보존이 필요할 때 새 스키마를 별도 승인 후 설계한다.

## 시간순 백테스트

1. 세션을 오래된 순서로 정렬한다.
2. 대상 세션보다 앞선 기록만 학습 입력으로 사용한다.
3. 동일한 과거 기록으로 단순 평균과 최근 가중 모델을 각각 계산한다.
4. 대상 세션의 실제 이동 중 속도와 비교해 절대오차를 계산한다.
5. 평가 사례가 2개 미만이면 평균오차를 표시하지 않는다.

대상 세션과 이후 세션은 해당 예측의 입력에 포함하지 않아 미래 데이터 누수를 막는다.

## 한계

- GPS만으로 동행 여부, 걷기 의도, 피로와 짐의 무게를 알 수 없다.
- 경사도와 노면, 날씨와 신호 대기는 모델 특성으로 사용하지 않는다.
- 3개 세션은 최소 표시 기준일 뿐 통계적으로 충분한 학습 완료를 의미하지 않는다.
- 최근 기록이 특정 상황에 치우치면 추정값도 그 영향을 받는다.
