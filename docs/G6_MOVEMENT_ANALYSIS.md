# G6 이동·정지 및 개인 보행 기초 통계

## 목적과 데이터 사용

- GPS 원본은 읽기만 하며 수정하거나 삭제하지 않는다.
- `quality-v1`의 포함·제외 판정을 재사용한다.
- 거리와 전체 측정시간 기준 평균속도는 기존 `metrics-v1` 값을 유지한다.
- 새 구간 분석은 `movement-v1`로 구분하며 현재는 브라우저에서 계산한다.
- DB 스키마와 RLS는 변경하지 않는다.

## `movement-v1` 판정 기준

1. `sequence_no`, `measured_at` 순으로 인접 GPS 지점을 연결한다.
2. 양 끝 지점이 모두 `quality-v1` 포함 상태여야 판정 후보가 된다.
3. 측정 시각 차이가 0 이하이거나 10초를 초과하면 판정 불가로 처리한다.
4. 좌표 속도가 3.5m/s를 초과하면 판정 불가로 처리한다.
5. 0~3.5m/s 범위의 기기 속도가 있으면 우선 사용하고, 없으면 좌표 거리/시간을 사용한다.
6. GPS 순간 흔들림을 줄이기 위해 현재 구간 앞뒤를 포함한 최대 5개 구간 속도의 중앙값을 사용한다.
7. 중앙값이 0.35m/s 이하면 정지, 0.7m/s 이상이면 이동, 그 사이는 판정 불가다.
8. 첫 GPS 전과 마지막 GPS 후처럼 관측되지 않은 측정시간도 판정 불가에 포함한다.

이동 중 평균속도는 이동으로 판정된 구간의 거리 합을 이동시간 합으로 나눈다. 기존 화면의 평균속도는 계속 품질 적용 전체 거리/전체 측정시간이며 정지시간을 포함한다.

## 여러 기록의 분석 대상 기준

다음을 모두 만족하는 완료 세션만 개인 보행 기초 통계에 포함한다.

- 전체 측정시간 60초 이상
- 품질 적용 거리 100m 이상
- 원본 GPS 지점 20개 이상
- 품질 통과 지점 비율 70% 이상

분석 가능한 세션이 3개 미만이면 개인 특성을 판단하기에 데이터가 부족하다고 표시한다. 3개 이상이어도 이 결과는 기초 비교 통계이며 머신러닝 학습 완료를 의미하지 않는다.

## 한계

- GPS 정지 흔들림이 연속적으로 발생하면 이동으로 잘못 분류될 수 있다.
- 매우 느린 보행은 정지 또는 판정 불가로 분류될 수 있다.
- 터널, 건물 내부와 백그라운드 전환으로 생긴 수신 공백의 실제 행동은 알 수 없다.
- 기기 속도 값의 제공 여부와 품질은 iPhone 및 브라우저 상태에 따라 다르다.
- 임계값을 변경할 때는 기존 결과를 덮어쓰지 않고 새 알고리즘 버전을 사용해야 한다.
