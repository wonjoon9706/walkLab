# T2-3 개인화 보행시간과 대중교통 탑승 가능성

## 시간 구성요소

- TMAP `sectionTime`: 공급자가 제공한 구간 원본시간으로 보존한다.
- 순수 보행시간: WALK 구간 거리 ÷ G7 선택 속도로 계산한다.
- G7이 `ready`가 아니면 G8과 같은 기본속도 정책을 사용한다.
- TMAP 문서는 도보 거리와 구간시간을 제공하지만 신호·계단·역사 접근시간 포함 범위는 명시하지 않는다. 따라서 TMAP 시간과 순수 보행시간을 합산하지 않고 비교값으로 표시한다.
- 지하철 개찰구·승강장 접근시간은 현재 데이터가 없으므로 `unknown`으로 유지하며 임의의 분 단위 값을 만들지 않는다.

## 버스 판정 정책

`여유시간 = 버스 절대 도착시각 - 정류장 순수 보행 도착시각`

- 120초 이상: 탑승 가능성 높음
- 30초 이상 120초 미만: 시간이 촉박함
- 30초 미만: 탑승 어려움
- 실시간 데이터가 120초보다 오래됐거나 누락: 확인 불가

이는 안전 여유를 둔 참고 판정이며 탑승을 보장하지 않는다. 첫 차량이 어렵고 두 번째 차량에 여유가 있으면 두 번째 차량을 후보로 선택한다.

## 순차 계산과 환승

첫 접근 도보는 계산 기준시각에서 시작한다. 탑승 가능한 첫 버스 후보가 있으면 차량 도착 절대시각에 TMAP 버스 구간시간을 이어 붙이고 다음 WALK 구간의 순수 보행시간을 계산한다. 이후 환승 교통편의 현재 실시간 응답은 미래 환승시점에 유효하지 않으므로 `requery_required`로 중단한다.

따라서 현재 단계에서는 실시간 최종 경로 ETA를 확정하거나 경로를 재정렬하지 않는다. 환승 시점 재조회와 경로 재정렬은 후속 단계 범위다.

## 자동 동작

사용자가 눌러 받은 기존 응답만 사용한다. 30초 화면 타이머는 절대시각 기반 여유시간과 만료 상태만 다시 계산하며 외부 API를 호출하지 않는다.
